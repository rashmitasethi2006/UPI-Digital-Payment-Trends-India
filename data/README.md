

# Dataset

This folder contains the monthly UPI statistics used in the project **UPI Growth and Digital Payment Trends in India (2016–2026)**.

The data is sourced from the National Payments Corporation of India (NPCI) and covers April 2016 to March 2026.

The dataset includes:
- Month
- Banks live on UPI
- Transaction volume (in millions)
- Transaction value (in crore rupees)

**Source:** [NPCI UPI Product Statistics](https://www.npci.org.in/what-we-do/upi/product-statistics)
